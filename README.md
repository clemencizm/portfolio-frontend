# Portfolio — Frontend Engineer

Bilingual (FR/EN) portfolio of case studies, built with Nuxt 4. Each project page is driven by a Markdown file: frontmatter feeds the components (timeline, challenges, metrics), the body feeds the tabs.

🔗 [Live site](https://clemence-lemaire.vercel.app/)

## Stack

- [Nuxt 4](https://nuxt.com) with [Nuxt Content v3](https://content.nuxt.com)
- [@nuxtjs/i18n](https://i18n.nuxtjs.org): French (default) and English, prefix strategy
- [Tailwind CSS v4](https://tailwindcss.com), design tokens declared in `@theme`
- Deployed on [Vercel](https://vercel.com)

## Technical decisions

- **One content collection per language and type** (`projects_fr`, `projects_en`, `home_fr`, …), generated by a single helper, so that components stay shared and only the Markdown is translated.
- **Tabs built from the Markdown AST**: the project body is split by `h2`, so a new section in a `.md` file appears without touching the code.
- **Accessibility**: WAI-ARIA tabs pattern with keyboard navigation, real links for the language switcher, `aria-current` on the active language, visible focus styles.

## Structure

​`
content/
  fr/ en/            → pages and projects, one Markdown file per language
i18n/locales/        → UI strings (fr.json, en.json)
app/
  pages/             → index, projects/[slug], stack
  components/        → Tabs, Timeline, Results, ChallengeCard, Gallery, LanguageSwitcher…
  assets/css/        → Tailwind theme and base styles
content.config.ts    → collections and Zod schemas
​`
